结算说明

说明项内容
结算批次平台根据交易数据自动生成，用于展示成功交易额、扣款、费用和应结算金额。
平台确认结算批次需由平台在 Admin 打款管理中确认，确认后进入可提现余额或平台打款流程。
结算规则默认 T+3，即交易完成后第 3 个工作日进入可结算流程。
金额计算应结算金额 = 成功交易额 - 总扣款 - 总费用。
提现申请提现申请是客户主动把可提现余额打到银行账户，对应 Admin 的提现审批和财务打款。
多币种余额USD、GBP、EUR 等余额分开管理，商户选择提现币种后，只能从该币种可提现余额中扣款。
汇率固定汇率在结算批次入账或未来 V2 换汇确认时固定，提现时间不会反向改变历史结算金额。
同币种提现USD / GBP / EUR 主币种钱包只支持提现币种与收款账户币种一致，例如 USD 余额提现到 USD 账户。
小币种钱包小币种钱包不能直接提现，需按申请当日汇率换算至 USD / GBP / EUR 后，再从主币种钱包发起提现。
提现手续费提现手续费由 Admin 在结算规则配置中维护，可配置固定费用、比例费用或组合费用，并在商户提现页面展示。
资金记录资金记录同时展示结算入账、提现冻结、提现完成、提现退回等记录，可通过记录类型筛选。
可能延后如遇节假日、风控复核、收款账户异常或银行退回，结算或打款时间可能顺延。
